### 58. A `#` comment before `[gd_resource]` breaks `.tres` loading; a `;` comment after the header is fine

**Symptom**
- Prepending a provenance/marker line to a generated `.tres` — e.g. `# GENERATED by tool … do not hand-edit\n` before the `[gd_resource …]` first line — makes the file fail to load: `ERROR: <path>:1 - Parse Error: Expected '['.` The resource loads as `null`; every `preload`/`load` of it cascades.
- Common when stamping generated resources with a "do not hand-edit" / hash / timestamp header.

**Cause**
Godot's text-resource (`VariantParser`) format requires the very first token to be the `[gd_resource …]` header block — anything before it is a hard parse error. But the parser **does** tolerate a `;`-prefixed comment line *inside* the body (after the first header line). `#` is not a comment leader in this format at all; `;` is.

**Fix**
Put the marker as a `;` comment line AFTER the `[gd_resource …]` header line, never a `#` line before it:
```gdscript
var lines := text.split("\n")
text = String(lines[0]) + "\n; GENERATED from foo.csv (hash=…) — do not hand-edit\n" + "\n".join(lines.slice(1))
```
Result loads fine:
```
[gd_resource type="Resource" script_class="LedgerSheet" format=3]
; GENERATED from ledger.csv (source-hash=af4099b50c06) — do not hand-edit
[ext_resource …]
```
(The `;` line is a *human* marker only — it survives on disk but is dropped if the editor ever re-saves the resource. Fine for a generator that is the sole writer.)

**Detect proactively**
Any code that writes a header/marker/banner into a `.tres` (or `.tscn`) generator output. If the marker text is prepended before `[gd_resource`, it will break loading — move it to a `;` line after the header. Headless-catchable: a `load()`/`preload()` of the stamped file (or a test that reads it back) surfaces the `Expected '['` immediately.

**Confirmed by**
2026-07-07 — `space-miner-game` GD-03 (task-022) balance generator. A/B probe: `# GENERATED …\n` prepended → `Parse Error: Expected '['`, loads=false; `; GENERATED …` inserted after the `[gd_resource]` line → loads=true. `tools/balance/generate.gd._stamp` uses the `;`-after-header form.
